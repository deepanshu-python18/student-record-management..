# Student Record Management System

## About
My first Python project! This program helps manage student records.

## Features
- Add student records
- View all students
- Search by name, age, or marks
- Calculate average marks
- Exit the program

## Technologies Used
- Python
- File Handling
- Functions
- Loops
- Exception Handling

## How to Run
1. Download student_management.py.
2. Open it in Python IDLE.
3. Press F5 to run.
